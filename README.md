# 📱 Smartphone Usage & Digital Addiction Well-Being Analytics

## 📌 Project Overview

This project is an interactive **Power BI dashboard** that analyzes smartphone usage, digital addiction, screen time, sleep patterns, social media usage, gaming behavior, stress levels, and academic/work impact.

The dashboard transforms raw user data into meaningful visual insights to help understand digital usage patterns and their relationship with well-being.

---

## 🎯 Objectives

- Analyze smartphone usage patterns.
- Identify different levels of smartphone addiction.
- Compare screen time across age groups and genders.
- Analyze the relationship between screen time and sleep.
- Study social media and gaming usage.
- Analyze stress levels and digital usage.
- Examine academic/work impact.
- Identify factors associated with smartphone addiction.
- Present insights through interactive Power BI visualizations.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. Load or refresh the dataset if required.
4. Navigate through the dashboard pages.
5. Use the slicers to filter the data.
6. Hover over visualizations to explore detailed values.
7. Explore the Key Influencers visual for additional analysis.
